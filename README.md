# TaskMitra Platform

TaskMitra is a company-owned service marketplace platform designed to connect skilled local workers with customers across Andhra Pradesh, India. The platform enables secure task posting, worker discovery, and transparent hiring through a modern web-based interface.

## Mission
To empower local workers with consistent job opportunities while providing customers with reliable, verified, and affordable services.

## Core Capabilities
- Secure phone OTP authentication
- Worker profiles with skills, experience, and availability
- Task creation and application workflows
- Hiring acceptance and completion tracking
- In-app messaging and ratings & reviews

## Technology Stack
- Frontend: React.js
- Backend: Firebase (Authentication, Firestore, Cloud Functions)
- Hosting: Firebase Hosting
- Payments: Razorpay (planned integration)

## Security & Trust
- Role-based access control
- Firestore security rules
- Admin moderation workflows
- Future-ready identity verification

## Target Market
Andhra Pradesh, India, with scalability across other Indian states.
